# portfolio_construction_theory
This repository contains Python notebooks and practical exercises
completed as part of my MiM Data Science & AI track at EDHEC Business School.

The goal is to strengthen my skills in Python, numerical computing,
data analysis, and quantitative finance through hands-on exercises.

Exercises based on the Portfolio Construction Theory course.

**Lecture 1 : Portfolio Valuation**
- Portfolio allocation and valuation
- Buy-and-hold and self-financing strategies
- Portfolio weights and returns
- Portfolio rebalancing
- Stock splits and dividends
- Adjusted stock prices

**Lecture 2 : Portfolio Expected Return and Risk**
- Expected returns
- Variance and volatility
- Covariance and correlation
- Portfolio diversification
- Portfolio risk calculations

**Lecture 3 : Global Minimum Variance Portfolio**
- Portfolio risk minimization
- Covariance matrices
- Matrix-based portfolio optimization
- Numerical optimization with SciPy
